# Student Performance Analysis

This project analyzes student performance data using Python. The dataset includes student scores in math, reading, and writing, along with demographic information.

## Features
- Summary statistics and missing value analysis
- Distribution plots of scores
- Gender-based performance comparison using pie charts


## This project uses basic concepts from mathematics and statistics:

- **Descriptive Statistics**: 
  - Measures like **mean**, **count**, **standard deviation**, **minimum**, and **maximum** via `df.describe()`
- **Distribution Analysis**: 
  - Histograms and **Kernel Density Estimation (KDE)** to visualize how scores are distributed
- **Group-wise Aggregation**:
  - Calculating **mean scores by gender** to explore performance differences using `groupby()`
- **Missing Value Analysis**:
  - Checking for missing data using `isnull().sum()`
- **advance maths and statistics**:
  - p-value
  - ANOVA
  - t-test
  - Post-Hoc Tukey Test Explanation


These concepts help understand patterns and variability in student performance.
